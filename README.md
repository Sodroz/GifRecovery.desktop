# GifRecovery
A desktop client only equicord plugin that lets you recover gifs from cache (gifs that load locally but link is dead) 

How to use:
Open gif picker - Rightclick on cached gif (but dead link) - Recover Gif - Attach or Download

Quick guide:
Direct your terminal to the userplugins folder src/userplugins
```shell
git clone https://github.com/Sodroz/GifRecovery.desktop
````
Then rebuild 
````
pnpm build
````
````
pnpm inject
````
All Done!

THIS IS FOR DESKTOP CLIENT ONLY AND ONLY WORKS FOR EQUICORD FOR NOW
